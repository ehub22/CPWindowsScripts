# EDIT THIS FILE FROM THE IMAGE README BEFORE RUNNING ANY SERVICE MODULE.
#
# Put ONE entry per line. Lines starting with # are ignored. Matching is
# case-insensitive. You may use:
#   * Windows service names      e.g.  TermService, W3SVC, DNS, Spooler
#   * Windows display names      e.g.  Remote Desktop Services
#   * Plain scenario words       e.g.  RDP, IIS, WEB, FTP, DNS, DHCP, AD,
#                                      SMB, FILES, PRINT, SQL, APACHE,
#                                      SSH, WINRM, EMAIL, SMTP, VPN
# The script expands the plain words into every related Windows service and
# will SKIP (never stop, disable, firewall-block or uninstall) anything that
# matches. Extra entries cost nothing. Missing entries can cost points.
#
# LISTED SERVICES ARE ALSO HARDENED AUTOMATICALLY (step 9C): services meant
# to stay get extra, service-specific hardening - Remote Desktop session /
# redirection options, IIS directory browsing + logging, FTP anonymous-auth,
# DNS zone-transfer restrictions, DHCP audit logging, SMB auditing, print
# driver restrictions (PrintNightmare), sshd_config, WinRM Basic-auth,
# SNMP community rights, and more - and they are made sure RUNNING.
# DEPENDENCIES ARE NEVER REMOVED: every service a listed service depends on
# (directly or indirectly) is protected too, and nothing is disabled while a
# running/auto-start/kept service depends on it.
#
# Two words have special meaning for hardening - use them ONLY if the README
# says so:  ANONYMOUSFTP = anonymous/public FTP logons must stay allowed;
# WEBDAV = IIS WebDAV publishing is required.
#
# The CyberPatriot Scoring Service, Windows Defender, Windows Firewall,
# Windows Update, Event Log and your VM guest-tools services are ALWAYS
# protected by the script itself - you do not need to list them here.
#
